# Frames

Grounds and borders of the game's windows: the dialog box (ground, border, header, gold border), the tooltip (ground, border), the quest page's parchment (questbg) and the chat ground. Edge textures hold eight pieces side by side (left, right, top, bottom, then the corners); the top and bottom are stored turned on their side. All are the game's own files from the WoW Forever client (1.60.1), as PNG; in an addon load them by their game path.
